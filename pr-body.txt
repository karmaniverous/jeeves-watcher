## Summary
Extracts `@karmaniverous/jeeves-watcher-core` as a new shared package in the monorepo.

### What moved to core
- Config schemas (base, inference, root, services) + barrel exports
- Config types (pure re-exports from schemas)
- Config defaults (pure data)
- Shared identity constants (COMPONENT_NAME, SERVICE_PACKAGE, PLUGIN_PACKAGE, DEFAULT_PORT)
- Schema tests (inference, moveDetection)

### What changed in service
- Imports schemas, types, defaults, and identity constants from core
- Pass-through re-exports preserved for public API compatibility
- Descriptor uses core constants instead of hardcoded values

### What changed in openclaw
- Imports shared constants from core (re-exports for rollup inlining)
- Removed duplicate constant definitions

### Release infrastructure
- Switched all 3 packages from auto-changelog to git-cliff
- Added cliff.toml per package (scoped tag patterns, include paths)
- Updated release-it hooks to use git-cliff
- Added git-cliff to root devDependencies
- Root build/typecheck/test scripts updated for core-first ordering

### Verification

- typecheck: all pass
- lint: all pass
- test: 581 tests, 75 suites, all pass
- knip: clean (tslib removed from core)
